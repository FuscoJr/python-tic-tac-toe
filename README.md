# 🎮 Tic Tac Toe in Python

This is my **first attempt** at building a Tic Tac Toe (X and O) game using Python.  
It was developed as part of my learning process (Milestone Project from the Python Bootcamp).  

## 📂 Project Files
- `Tic_Tac_Toe_Projekt.ipynb` → Jupyter Notebook version  
- `Tic_Tac_Toe_Projekt.py` → Python script version  

## ✨ Features
- Two-player mode (Player 1 vs Player 2)  
- Random selection of who goes first  
- Input validation (choose only free spots)  
- Win and tie detection  
- Replay option  

## 🚀 How to Run
1. Clone this repo:
   ```bash
   git clone https://github.com/FuscoJr/tic-tac-toe-python_V0.5.git
   cd tic-tac-toe-python_V0.5
2. python Tic_Tac_Toe_Projekt.py
3. jupyter notebook Tic_Tac_Toe_Projekt.ipynb
